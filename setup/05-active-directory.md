# 05 — Active Directory and identity telemetry

**Status: PLANNED; no domain controller is currently verified.**

## Goal

Add a disposable lab-only Windows Server/domain controller and safely examine domain identity events, with no integration to real school, employer, or personal production domains.

## Definition of done

- [ ] Create a Windows Server VM and record verified OS/IP.
- [ ] Configure isolated lab DNS and directory services.
- [ ] Create disposable domain identities and appropriate auditing.
- [ ] Enroll and observe an authorized Windows endpoint.
- [ ] Send relevant Windows Security events to Wazuh and correlate them.
- [ ] Write an evidence-based domain authentication scenario.
